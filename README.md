Все данные и коды

Данный раздел содержит данные и код для методов.

Если поставить горизонт 1 - будет прогноз на 1 шаг.

Данные:\

1) Реализованные волатильности и средние дневные цены закрытия: https://cloud.mail.ru/public/kGzT/JSqQrRryJ

2) Одношаговые прогнозы с вейвлетами и без: https://cloud.mail.ru/public/3kiS/Pf3bX3tvX \
В папках лежат прогнозы моделей: TCM, CTCM, CNN, XGBoost, Nixtla, Prophet, ARIMA \
Все модели используются с вейвлетами и без. \
Спецификация в файлах указывается как "модель"\_"wavelet"\_"mode"\_"level"

4) Массовое сравнение моделей при прогнозировании на несколько шагов вперед: https://cloud.mail.ru/public/7Dsp/CZBuK1XXF
Описание: \
"подход к прогнозированию" = ['rekurs', 'posled'] \
"подход к прогнозу NN" = ['individual', 'recursive', 'direct'] \
"подход к прогнозу XGBoost" = ['recursive', 'individual', 'multioutput'] \
"тип актива" = ['ts', 'rv'] \
"оптуна" = 1 - использовалась, 0 - не использовалась \
"тип погрешности для оптуна" = ['smape_interv', 'smape_tochech']

   1) В папке TCM лежат результаты прогнозов методом TCM на несколько шагов вперед. Папка содержит файлы следующего типа и вида:
      - tcm-"подход к прогнозированию"\_progs_1_"актив"_"тип актива" - прогнозы в разных подходах. Строки - прогноз на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
      - tcm-"подход к прогнозированию"\_time_1_"актив"_"тип актива" - количество секунд, затраченное на рекурсивный прогноз на каждом интервале
      - tcm-"подход к прогнозированию"\_toch_1_"актив"_"тип актива" - точные значения рядов. Строки - точные значения на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
   2) В папке Statsforecast лежат результаты прогнозов методами из пакета Statsforecast на несколько шагов вперед. Важно понимать, что в самих файлах лежат результаты лучших моделей из этого пакета. Обозначение лучшей модели лежит в отдельном файле для типа актива. Папка содержит файлы следующего типа и вида:
      - Statsforecast_best_models_"тип актива" - содержит лучшие модели из пакета Statsforecast. Именно их результаты представлены в файлах с прогнозами
      - Statsforecast_progs__"актив"_"тип актива" - прогнозы. Строки - прогноз на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
      - Statsforecast_time__"актив"_"тип актива" - количество секунд, затраченное на рекурсивный прогноз на каждом интервале
      - Statsforecast_toch__"актив"_"тип актива" - точные значения рядов. Строки - точные значения на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
   3) В папке Nixtla лежат результаты прогнозов методами из пакета Nixtla (TimeGPT v1) на несколько шагов вперед. Важно понимать, что в самих файлах лежат результаты лучших моделей из этого пакета. Обозначение лучшей модели лежит в отдельном файле для типа актива. Папка содержит файлы следующего типа и вида:
      - Nixtla_best_models_"тип актива" - содержит лучшие модели из пакета Nixtla. Именно их результаты представлены в файлах с прогнозами. Для rv добавляется еще "_цифра от 1 до 10", т.к. было несколько итераций.
      - Nixtla_progs__"актив"_"тип актива" - прогнозы. Строки - прогноз на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
      - Nixtla_time__"актив"_"тип актива" - количество секунд, затраченное на рекурсивный прогноз на каждом интервале
      - Nixtla_toch__"актив"_"тип актива" - точные значения рядов. Строки - точные значения на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
   4) В папке Prophet лежат результаты прогнозов методом Prophet в дефолтной конфигурации и с оптимизацией гиперпараметров через Optuna по двум метрикам - точечный и интервальный smape. Папка содержит файлы следующего типа и вида:
      - Prophet"оптуна"\_progs\_"тип погрешности для оптуна"\_"актив"\_"тип актива" - прогнозы. Строки - прогноз на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
      - Prophet"оптуна"\_time\_"тип погрешности для оптуна"\_"актив"\_"тип актива" - количество секунд, затраченное на рекурсивный прогноз на каждом интервале
      - Prophet"оптуна"\_toch\_"тип погрешности для оптуна"\_"актив"\_"тип актива" - точные значения рядов. Строки - точные значения на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
   5) В папке NN лежат результаты прогнозов через CNN с разными типами подходов к прогнозированию. Папка содержит файлы следующего типа и вида:
      - NN_progs\_"подход к прогнозу NN"\_"актив"\_"тип актива" - прогнозы. Строки - прогноз на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
      - NN_time\_"подход к прогнозу NN"\_"актив"\_"тип актива" - количество секунд, затраченное на рекурсивный прогноз на каждом интервале
      - NN_toch\_"подход к прогнозу NN"\_"актив"\_"тип актива" - точные значения рядов. Строки - точные значения на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
   6) В папке XGBoost лежат результаты прогнозов через XGBoost с разными типами подходов к прогнозированию. Папка содержит файлы следующего типа и вида:
      - XGBoost_progs\_"подход к прогнозу XGBoost"\_xgboost_forecast\_"актив"\_"тип актива" - прогнозы. Строки - прогноз на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
      - XGBoost_time\_"подход к прогнозу XGBoost"\_xgboost_forecast\_"актив"\_"тип актива" - количество секунд, затраченное на рекурсивный прогноз на каждом интервале
      - XGBoost_toch\_"подход к прогнозу XGBoost"\_xgboost_forecast\_"актив"\_"тип актива" - точные значения рядов. Строки - точные значения на энный шаг, столбцы - к какому диапазону точных значений относится этот прогноз
